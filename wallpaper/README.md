# MIKOTO URABE — версия без Wallpaper Engine

Браузерная реконструкция сцены из архивных файлов обоев: фон 3840×2160,
дождь, живая дата/время и музыкальный плеер, который показывает текущую
музыку или видео из Windows.

## Быстрый запуск

- Двойной щелчок по **`start.bat`** — он запустит медиа-мост и откроет обои.
- Либо откройте **`mikoto-urabe.html`**; мост можно запустить отдельно:
  `..\media-bridge\start.bat`.
- `F` — на весь экран, `Space` — пауза.
- Клик по обложке — пауза/воспроизведение, клик по полосе — перемотка.

## Медиа из Windows

Плеер подключён к системному медиа-сеансу Windows (SMTC), поэтому показывает
то, что играет в Spotify, VLC, Media Player, Chrome, Edge и т.п.:

- название, исполнитель и альбом/источник;
- обложку (нативные плееры отдают её через Windows);
- реальную длительность, позицию и состояние play/pause;
- полоса и время показывают именно текущий отрезок: для нативных плееров
  позиция берётся из Windows, для YouTube/браузера — из ползунка плеера
  через UI Automation (Windows иногда отдаёт для YouTube позицию 0);
- тип: музыка или видео — меняется иконка и цвет акцента;
- для **YouTube / YouTube Music** превью ролика подтягивается автоматически
  по ссылке из браузера и ставится обложкой;
- если ничего не играет — «Nothing playing».

Для браузерных сайтов, кроме YouTube, Windows/Chromium обычно не отдаёт
картинку ролика. Тогда показывается аккуратная иконка «видео» вместо обложки.
Нативные плееры (Spotify, VLC, Media Player) отдают обложку нормально.

## Медиа-мост

`media-bridge` — маленький локальный помощник, который читает Windows
Media Session и отдаёт состояние на `http://127.0.0.1:47823`. Он уже запущен
и добавлен в автозапуск (ветка `HKCU\...\Run`, без прав администратора).

- Запустить вручную: **`media-bridge\start.bat`**.
- Убрать из автозапуска: **`media-bridge\remove-autostart.bat`**.
- Порт слушает только `127.0.0.1`; удалённые сайты получают 403.

## Как поставить на рабочий стол без Wallpaper Engine

1. Установите бесплатный **Lively Wallpaper** (Microsoft Store или GitHub:
   `rocksdanister/lively`).
2. В Lively нажмите **Add Wallpaper** и выберите **`mikoto-urabe.html`**.
3. Готово. Медиа-мост уже стартует вместе с Windows, поэтому плеер будет
   подхватывать музыку/видео.

Если Lively попросит картинку-превью, используйте **`poster.jpg`**.

## Файлы

| Файл | Назначение |
|---|---|
| `mikoto-urabe.html` | самодостаточная версия обоев (всё встроено) |
| `index.html` | редактируемая версия (`bg.png`, `album.png`, `fonts.css`) |
| `bg.png` | фон, извлечён из `scene.pkg` (3840×2160) |
| `poster.jpg` | статичный кадр 3840×2160 |
| `../media-bridge/` | локальный медиа-мост и скрипты автозапуска |

## Примечания

- Это самостоятельная реконструкция, а не запуск движка Wallpaper Engine.
- Оригинальные обои: **MIKOTO URABE** (Nazo No Kanojo X),
  Steam Workshop `3491127388`, автор `negro_nazi`.
- В архиве нет аудио: обои не воспроизводят музыку сами, а показывают то,
  что играет в системе.
